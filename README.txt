AI Sustainable Route Optimizer — Fixed Website
1. Extract the ZIP.
2. Open index.html in Chrome or Edge.
3. The sample scenario runs automatically.
4. Use "Load Sample CSV" to reset.
5. Upload your own CSV with: id, lat, lon, demand_kg, service_min.
6. Edit vehicle names/capacities.
7. Click Run Optimization.
8. Click Download Optimized Allocation CSV.

Internet is required for the map (Leaflet/OpenStreetMap) and charts (Chart.js CDN).

Academic note: this browser version uses a Least-Cost-style feasible transportation allocation and presents the MODI/Simplex framework for the academic model. It does not pretend to be a full mathematical Simplex/MODI solver. A next version can implement exact transportation Simplex/MODI cell-by-cell.
